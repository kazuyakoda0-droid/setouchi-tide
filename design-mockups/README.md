# しおどき リデザイン候補

本番の生成ロジックやスタイルを変更せずに比較できる、3方向のデザインモックアップです。

## 3案の狙い

- A「Sea Glass」: 現在潮位と次の満干潮を最短で把握できる、万人向けの第一候補。白・水色・コーラルで清潔感と親しみを両立。
- B「Weekend」: 釣り、磯遊び、夕涼みなど「潮を見た次に何をするか」を提案。ファミリーやライトユーザー向け。
- C「Night Deck」: 夜釣り・屋外利用での視認性を重視。暗い背景、高コントラスト、大きな数値でヘビーユーザー向け。

## フォント方針

明朝体は使わず、モックアップでは既存の自前配信フォント `Zen Kaku Gothic New` を全案に使用しています。丸みのある字形、太めの見出し、広めの行間でやわらかさを出しています。本番採用時にさらに親しみを強めたい場合は `Zen Maru Gothic` への置き換えも候補です。

## 競合調査から採り入れた要素

- 地点検索をページ上部で明確にする
- 現在潮位、潮の向き、次の満干潮までの時間を一つの主役カードに集約する
- お気に入りや最近見た地点を想定した再訪導線を用意する
- 釣りや潮干狩りなど、利用目的に結びつく時間帯を示す
- グラフと数値を同時に読めるよう、満潮・干潮の情報を近接配置する

表示数値はレイアウト確認用のモックデータです。
